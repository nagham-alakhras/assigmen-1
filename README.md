
# Leon - Creative Agency Website

##  About The Project

Leon is a creative agency landing page designed using HTML and CSS.
The project focuses on a clean, modern, and minimal design with a responsive layout that adapts to different screen sizes.

##  Technologies Used

- HTML5
- CSS3
- Bootstrap
- Font Awesome

##  Features

- Clean and modern user interface.
- Responsive design for mobile, tablet, and desktop.
- Landing section with background image.
- Features section.
- Services section.
- Font Awesome icons.
- CSS Grid and Flexbox layouts.
